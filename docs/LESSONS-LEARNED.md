**Scope:** Retrieved conversation history (July–November 2026), current-thread logs, owner feedback and inspected v2 repository documents and source at PR #34. This is not a guaranteed complete transcript audit. Older Astro repository lessons transfer as process lessons only; its branches and unfinished modules are not assumed to be v2 features or requirements. Prior assistant statements are historical reports, not independently verified facts unless corroborated. Avoid blame; name the defect and change the process.

## Operational changes

Before implementing: inspect actual existing route/content, relevant original owner decision, exact baseline, overlapping PRs, source quality and acceptance. Before handoff: verify artifact contents, validate syntax/anchors, test one end-to-end affected journey if available, report precisely what could not be run. Before merge: full exact-head local and hosted gates, no skipped security, no force, explicit stage list. After merge: confirm production alias and representative live pages. Track each issue in the roadmap with a concrete next action. Record what was discovered, corrected, rejected and why. Preserve history; do not maintain a growing pile of conflicting “remaining” documents.

**Owner clarification, 25 November 2026:** Copy changes must never be release blockers. Hard-coded marketing/legal prose, headings, labels, forbidden words and narrative hashes create artificial regressions. Test functionality, structured facts and data fidelity; editorial review owns language.
